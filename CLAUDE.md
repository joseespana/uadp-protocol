# Cosmos — UADP Demo Universe

## Overview
Cosmos is a collection of microservices simulating a complete UADP ecosystem for the Astral browser demo. Each service simulates a real-world service (social network, bank, store, etc.) with fictional data centered around the user **Jose Espana**.

## Stack
- **Runtime:** Bun 1.x
- **Framework:** Elysia (fastest HTTP framework on Bun)
- **Language:** TypeScript end-to-end
- **Data:** JSON files loaded in memory at startup
- **Monorepo:** Bun workspaces
- **Deploy:** Docker Compose

## Architecture

```
Gateway :4000 → routes to all services
  ├── Nova    :4001  — Text social network (Twitter-like)
  ├── Pulse   :4002  — Visual social network (Instagram-like)
  ├── Orbit   :4003  — Primary bank
  ├── Zinc    :4004  — Neobank / international card
  ├── Market  :4005  — Online store (Amazon-like)
  ├── Stream  :4006  — Video platform (YouTube-like)
  ├── Echo    :4007  — Messaging (WhatsApp-like)
  ├── Herald  :4008  — News portal
  ├── Lyra    :4009  — Music streaming (Spotify-like)
  ├── Vortex  :4010  — Movies & series (Netflix-like)
  ├── Beacon  :4011  — Email (Gmail-like)
  ├── Compass :4012  — Maps & ride-hailing (Uber-like)
  ├── Flame   :4013  — Food delivery (Rappi/UberEats-like)
  └── Atlas   :4014  — Calendar & events (Google Calendar-like)
```

## Key Commands
```bash
bun install          # Install all dependencies
bun run seed         # Generate fictional data (~2 seconds)
bun run dev          # Start all services in parallel
docker compose up    # Start everything via Docker
```

## UADP Protocol
Every service exposes:
- `GET /.well-known/uadp.json` — Service manifest with `ai_hints`
- `POST /uadp/v1/auth/challenge` — Mock token challenge
- Standard UADP endpoints under `/uadp/v1/`

All responses use `uadp_type` field and follow UADP+JSON format.

## Fictional User — Jose Espana
- 34yo CTO & full-stack developer in San Francisco
- Founder of Perseusoft, paid biweekly (1st and 15th)
- Active on Nova, has a Stream channel ("Code with Jose"), shops on Market
- Two bank accounts: Orbit (primary) and Zinc (international)
- All data in English, amounts in USD

## Data Rules
1. No real data — all names, addresses, IDs are fictional
2. Temporal coherence — Market purchases match Orbit charges on same day
3. English for user-facing text and technical fields
4. Realistic amounts and patterns
5. No real brand names — use fictional alternatives
6. Images via `https://picsum.photos/seed/{id}/{w}/{h}`

## Code Conventions
- Each service is a single Elysia app in `services/{name}/src/index.ts`
- Use Elysia's built-in TypeBox validation (no Zod)
- SSE via Elysia's native generator functions
- Data loaded from `data/jose_espana/` JSON files via `cosmos-core` loader
- All services share types from `cosmos-core`
